# 修復後驗收（重跑比對）

各單位修完後，PM 會問「還剩多少、剩的是什麼」。只回總數不夠，要能說出每一列的分類。

1. **流程**：V0 總覽（各步驟剩幾筆）→ 有剩的步驟撈明細匯出 → 用業務鍵（工單＋元件項次、計畫單＋元件項次）逐列對回發出的清單 → 分類：

| 分類 | 條件 | 處理 |
|---|---|---|
| 清單未做 | 在清單上，現在還錯 | 追負責單位 |
| 改一半 | 在清單上，只對一部分欄位 | 換做法重做 |
| 清單外新增 | 不在清單上，屬於這次範圍 | 查原因，補進待辦 |
| 範圍外 | 不在清單上，例如匯入的舊單據 | 交 PM 決定 |

2. **總覽數字先對齊範圍再比**：總覽直接看 RESB 現況，會含系統轉換匯入的舊工單；兩者可能差到一個數量級（公司實例見 `company-cases.md`）。數字差很多時先說明範圍差在哪。
3. **先套用 PM 在清單上標的「不處理」再比對**，不然會被算成「清單未做」。PM 的排除規則要寫成系統條件，套到清單外新增與範圍外。
4. **規則裡的條件找系統依據**：例：「已完工已關帳不處理」的「關帳」用過帳期間判斷：
    1. MM：`MARV`（`LFGJA/LFMON` 目前、`VMGJA/VMMON` 前期、`XRUEM` 前期可過帳 🔶）。
    2. FI：`T001-OPVAR` → `T001B`（`BUKRS` 欄位＝變式、`RRCTY = '0'`、`MKOAR = '+'`）。一般月份看**區間 2**（`FRYE2/FRPE2/TOYE2/TOPE2`），區間 1 可能只開年結特殊期間。
    3. 入庫期間（MATDOC 101 最大 `BUDAT`）早於兩者可過帳的期間 → 已關帳。這是「系統能不能過帳」，財務月結進度以財務為準。
5. **補兩種完工日**：實際完工日 `AFKO-GETRI` 🔶、最後入庫日 MATDOC 101 最大過帳日；不要用 `GLTRI`（原因見 `repair-execution.md` 第 4 點）。公司自建的同步程式對已入庫工單可能不會同步，要在清單註明（公司實例見 `company-cases.md`）。
6. **剩餘待辦 Excel**：總覽一頁（步驟、負責單位、原本、剩餘、狀態），每個步驟一頁只列要處理的列；排除了什麼、為什麼寫在每頁上方，不列出排除的列；第一次做時把格式寫成一份說明，之後照著產出。
7. **沿用發出清單的編號與檔名**：發出去的是步驟1～6，就只用這些；沒編號的清單沿用檔名，不要自己編「步驟7」。內部操作步驟文件的編號不同時，對外一律用清單的。
